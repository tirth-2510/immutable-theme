# Immutable Theme

A dark VS Code theme built around one idea: pick it once, and you never feel the need to switch again.

No color bursts, no neon accents fighting for attention — just a calm, elegant dark palette that stays out of your way while you work. That's where the name comes from: it's meant to be *immutable*, the last theme you install.

## Included Variants

- **Immutable** — the base theme: a clean, muted dark palette with black-and-yellow accents.
- **Immutable (Black - Green)** — the same base theme, with notification colors changed from yellow to green.
- **Immutable (Black - Yellow)** — the base theme with its default black-and-yellow accents made explicit as its own selectable variant.
- **Immutable (GPT theme)** — a separate variant inspired by the color palette used in the ChatGPT mobile app.

## Installation

1. Open the Extensions view in VS Code (`Ctrl+Shift+X`).
2. Search for **Immutable Theme**.
3. Click **Install**.
4. Open the Command Palette (`Ctrl+Shift+P`) → **Preferences: Color Theme** → pick your variant.
